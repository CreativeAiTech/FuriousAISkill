---

**Changes**
- Replace the 90-percent, high-effort-only, 30-day-expiry gate with a frozen absolute bar: 85% of the 58-point AA v4.3.2 leader, 49.3 points (`authority.bar`). The score at the exact listed effort alone decides; no effort floor, no expiry (future-dated `checkedAt` still rejected). `default` and unreported efforts never qualify. `bar.percent` below 85 is rejected in code, and `bar.score` below the code-pinned `FROZEN_BAR` for the benchmark version (49.3 for v4.3.2) is rejected, so data alone can raise the bar but never lower it.
- Add `modelAuthority.mjs check <model> --effort <effort> [--table] [--prices]` and exported `brainCheck`: brain verdict, code name, preferred/overkill/eligible tier and permissions derived in code (never read from JSON). Exit 0 brain, 2 not a brain, 1 usage/read error. The positional and `--qualification` forms are unchanged.
- Add `models` (code names, tools) and `brains` (preferred and overkill per tool) to `model-ranks.json`. A listing orders eligible brains and never grants brain status. `delegateTo` comes from `model-prices.json` output rates; a price failure never changes the verdict.
- Update the authority reference, README and tier tests (Astra medium and high now qualify; a low effort is the fallback case).

**Why**
A rolling 90%-of-leader cutoff moved whenever a stronger model shipped and excluded cheap, adequate brains such as Opus 5.5 medium. A frozen bar plus per-tool preferred and overkill lists lets the cheapest qualified brain decide by default.

**Measure**
Run `node --test tools/modelAuthority.test.mjs tools/modelTier.test.mjs tools/modelEconomics.test.mjs`, then `node tools/modelAuthority.mjs check claude-opus-5-5 --effort medium` (exit 0) and `check gemini-3.8-flash --effort high` (exit 2). This uses the recorded v4.3.2 scores, not new model trials.
