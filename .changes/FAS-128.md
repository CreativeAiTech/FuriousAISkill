title: Memory hygiene audit for Claude Code memory dirs
---

**Changes**
- Add `tools/memoryHygiene.mjs`: a generic, dependency-free audit of a file-based memory dir. REPORT level lists findings (stale branch or path, duplicate memories, memories restating a rule, conditional caveats, filename drift, retired-but-routed, index problems), each with file:line and quoted evidence, plus informational store sizes. SAFE-FIX level (`--fix`) only appends missing MEMORY.md index lines after a timestamped backup and a log entry, and is idempotent.
- `--index-out <file>` writes a regenerable topic-grouped index (by `metadata.type`, with links and a token count) outside the memory dir; `--json` adds `sizes.indexTokens`.

**Why**
Memories go stale silently (wrong default branch, dropped tools, caveats whose condition is met). A daily report lets a brain fix them cheaply while the automated level stays mechanical and reversible.

**Measure**
Run `node --test --test-timeout=60000 tools/memoryHygiene.test.mjs`; then `node tools/memoryHygiene.mjs --repo <project>` and read line 1 (finding counts).
